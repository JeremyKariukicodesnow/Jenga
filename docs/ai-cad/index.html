OPEN SOURCE · AI-COMPATIBLE CAD

One workspace for
schematics, boards and 3D.

Jenga is a Windows electronics workspace for creating modern KiCad-compatible designs. You can work directly in the desktop app or connect an external assistant through deterministic MCP, CLI and JSON tools.

WHAT YOU CAN MAKE

01 / SCHEMATICS

Clear connected circuits

Create symbols, draw complete visible wires, inspect nets and export native schematic files.

02 / PCB

Independent or linked boards

Build a board by itself or from a schematic, assign footprints, route copper and verify the result.

03 / 3D

Assemblies you can inspect

Use compatible component models, orbit the assembled board and export review images or CAD formats.

04 / ASSISTANTS

Explicit engineering operations

External AI assistants can inspect, preview and commit revision-guarded operations without pretending to be the electrical engineer.

05 / OPEN FILES

Modern KiCad exchange

Import or export supported native projects, schematic files, PCB files and reusable assets.

06 / REVIEW

Keep judgment in the loop

Run ERC and DRC, review part data and test hardware. A clean CAD result is not a certification.
