# Project showcase exports

These PNGs are unmodified exports copied from Jeremy's local 555 Pulse Generator, Maize Factory, and Access Terminal S3 projects for the public Jenga showcase. They show design artifacts, not fabricated or certified hardware. The terminal remains subject to engineering review, as described on the website. The Maize Factory project is represented by its power and control schematics only.

The GLB files are actual exported 3D assemblies, not turntable videos. Native schematic and PCB files are offered for inspection. Native boards can reference project-specific external models or libraries; the self-contained GLB is the portable visual assembly. Downloads are development examples, not manufacturing-approved designs.
