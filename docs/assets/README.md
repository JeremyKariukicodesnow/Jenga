# README artwork

`jenga-hero.png` was generated for Jeremy's Jenga repository using the built-in OpenAI image generation tool, with ChatGPT/Codex assistance. It is conceptual electronics artwork, not a screenshot, functional circuit, certified PCB or KiCad/OpenAI endorsement. No third-party logo or stock image was supplied as an input. Do not use it as electrical design evidence.

Prompt: Create a polished wide 16:9 editorial hero illustration for the GitHub README of Jenga, an independent open source electronic CAD application. A refined light ivory technical drafting sheet background, a precise dark ink schematic circuit at left flowing into a realistic forest-green printed circuit board with copper traces, ICs, resistors and pin headers in isometric view at right. Restrained red accent dots and fine blueprint grid. Sophisticated clean engineering visual, generous negative space, tactile realistic PCB materials, sharp legible composition, no fake app screenshots or fabricated UI. Put only the exact word JENGA in large dark dot-matrix lettering at upper left and the small exact line Schematics · PCB · 3D below it. No KiCad logo, no other logos, no certification marks, no claims of production readiness. This is a conceptual illustration, not a screenshot.

The download page reuses the owner-supplied `resources/branding/jenga.png` and `.ico` byte-for-byte as `jenga-logo.png` and `jenga.ico`. `jenga-wordmark.svg` reproduces Jenga’s original 5×7 dot glyphs from `crates/jenga-desktop/src/design.rs`; it does not use a proprietary font.
