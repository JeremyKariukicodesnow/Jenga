BUILT FOR YOUR WORKBENCH

01 / DESIGN

Schematics & symbols

Draw connected circuits, create reusable symbols, work with project and personal libraries, and inspect electrical connections.

02 / BUILD

Boards & footprints

Place footprints, route copper, inspect layers, link component models and review board checks.

03 / SEE

3D & exports

Inspect assemblies, export review images and native design files, and move between Jenga and modern KiCad formats.

04 / ASSIST

AI through MCP & CLI

Let your chosen assistant inspect projects, edit designs and run engineering operations using explicit tool calls.

05 / VERIFY

Review the result

Use connectivity checks, operation status and native validation alongside component datasheets and engineering judgment.
